Twelve gods, eleven events

Gateways is a national inter-collegiate tech fest, run by the postgraduate students of CHRIST University’s Department of Computer Science for 28 years. Each year it gets a theme. In 2024 the theme was techOlympus: ancient myth meeting modern technology.

The theme became the site’s structure. Zeus anchors the home page, and each of the other eleven gods presides over one event, its name always leading:

  • Technical: Aphrodite’s Aurora (UI/UX), Ares Techwar (a 24-hour hackathon), Hermes’ Bytechase (capture the flag), Athena’s Arena (IT quiz), Hephaestus’ Forge (IoT), and Poseidon’s Code Current (coding and debugging).
  • Non-technical: Apollo’s Luminous Lens (photography), Dionysus’ Battleground (gaming), Artemis’ Adventure (treasure hunt), Hades’ Tech Authority (IT manager), and Hera’s Trials (a surprise event).

The events page splits into two pantheons, technical and non-technical, and every event page carries its god’s portrait.

Gold on black, temple and terminal

  • Palette. Near-black pages with one antique gold, #E7B472, for every heading and line. Gold scrollwork divides each section.
  • Type. Abril Fatface for headings. A swash script for the techOlympus wordmark. Caesar Dressing for the countdown. Monospace for body text, so it reads as temple meets terminal.
  • Motion. The event shields redraw their gold outlines as they enter. Lightning and smoke move behind Zeus, and gold leaves drift down every event page.

Built to be updated by the fest team

The site is a React app on Vite and Tailwind. GSAP and Framer Motion handle the movement, Vivus draws the gold outlines, and AOS handles reveals. It’s hosted on Vercel.

Event details aren’t hard-coded. Each event page fetches its content from a shared JSON file, so the organisers could change rules, venues and timings without a redeploy. Registration goes to Google Forms, with one ₹150 fee covering any number of events.
